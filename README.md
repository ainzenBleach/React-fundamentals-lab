# React-Fundamentals

This repository was created with the goal of **building and demonstrating a solid foundation in React** through practical examples, component-based architecture, and clean code practices.

The focus is not only on making things work, but on **understanding how and why React works**.

---

## 🎯 Project Purpose

- Learn and reinforce the core concepts of React
- Build a strong foundation for more advanced applications
- Practice componentization and code organization
- Serve as a study reference and portfolio project

This project is part of my **professional portfolio as a Front-end developer**.

---

## ⚛️ Concepts Covered

- Basic React project structure
- Functional components
- JSX
- Props
- State management (`useState`)
- Conditional rendering
- Folder organization
- Initial best practices

---

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Node.js (development environment)
- Git & GitHub

---

## ▶️ How to Run the Project

1. Clone the repository:
   git clone https://github.com/your-username/React-Fundamentals.git
2. Navigate to the project folder:
   cd React-Fundamentals
3. Install the dependencies:
   npm install
4. Start the application:
   npm start
5. Open in your browser:
   http://localhost:3000
